# 涂鸦世界 V2 玩法设计

一句话：**世界本来是彩色的。墨潮把颜色抽走，留下黑白线稿；玩家和朋友一起把颜色还回来，或者按自己的想法重新涂。**

本稿替代 [game-design.md](game-design.md)。旧存档和旧协议不兼容，不做迁移。世界生成算法见 [world-generation.md](world-generation.md)，技术分层见 [architecture-v2.md](architecture-v2.md)。

## 1. 为什么重做

| 现状                                        | 问题                                              |
| ------------------------------------------- | ------------------------------------------------- |
| 无限生成，每区块同一配方（十字路 + 4 栋楼） | 没有"去哪里"的理由，地图没有记忆                  |
| 每个区块都要调一次模型                      | 贵、慢、无密钥不能玩；AI 只生成几何，玩家感受不到 |
| 住宅室内是空的                              | 最贵的内容没有玩法                                |
| 固定职业，创建时锁定                        | 为射击生存设计，新东西（笔刷、坐骑）塞不进去      |
| 属性点 5% 概率 + 保底                       | 手游留存设计，朋友间本地游戏里只会让人觉得被耍    |
| "涂鸦"只是画风                              | 玩家对这张画什么都做不了                          |

## 2. 世界结构

```text
野外（无限，噪声生成，无 AI）
  ├── 教学城（固定模板，出生点）
  ├── 入口地标 ──► 城市副本 A（有限，永久，道路生长 + AI 风格 + 模板）
  ├── 入口地标 ──► 城市副本 B
  ├── 遗迹（程序模板，藏颜色）
  └── 颜料来源（花田、矿脉、湖面）
```

| 层       | 范围                  | 生成                                             | 存盘                   | 玩法                       |
| -------- | --------------------- | ------------------------------------------------ | ---------------------- | -------------------------- |
| 野外     | 无限                  | 噪声 + 模板，确定性，不用 AI                     | 不存地形，只存玩家改变 | 探索、采集、移动、墨污生物 |
| 城市副本 | 有限（默认 5×5 区块） | 创建时一次：道路生长 → 街块 → AI 风格 / 模板兜底 | 整座城落盘             | 上色、墨潮、居民诉求、通关 |

- 城市是**永久**的：同一入口进去永远是同一座城，有名字，进度保存。城 ID 由入口地标坐标哈希得到。
- 进城是现有"进住宅室内"的同一套场景切换：独立空间、房主确认、访客校验后传送、工具和血量沿用。
- 一个世界**同时只能打开一座城**；要进另一座城，城里的人得先出来。玩家可以分散在野外和城里，房主模拟全部。
- 野外和城市都有**原色**：野外的原色由群系决定，城市的原色由模板和 AI 的配色方案决定。墨污抽走颜色，画面变成黑白线稿。
- 野外的黑白程度是城市进度的派生状态：离墨污城市近的野外褪色，城市通关后周围 N 个区块恢复原色、墨污生物减少。不存任何野外颜色数据，按城市状态实时算。

## 3. 核心循环

**还色是目标，战斗和移动是手段，敌人是阻碍而不是目的。**

```text
野外：看见远处地标 → 滑翔 / 骑行过去 → 沿途采颜料、打墨污生物
  → 进城：击退据点 → 修复原色或自己涂鸦，把街区的颜色还回来 → 居民回来、画室开门
  → 守墨潮 → 全城有色通关 → 周围野外恢复颜色，城门可传送
  → 去下一座城
```

两种玩家走同一条路：只想把世界修好的人用修复笔刷，不用选颜色；想创作的人用涂鸦笔刷覆盖原色。进度只看"有没有颜色"，不看是谁的颜色。

### 3.1 起点

出生在**教学城**门口。教学城是固定模板，不用 AI，3×3 区块，前 10 分钟教会上色、打墨污、见一次小墨潮。出城门是野外，视距内能看见第一座真正的城的地标。新建世界不需要等任何生成。

## 4. 城市

### 4.1 区块状态机（每区块持久，房主裁定，补丁式存档）

```text
抽色 ──据点清空──► 清理 ──有色率达标──► 有色 ──诉求全部完成──► 繁荣
  ▲                 │
  └──侵蚀归零────────┘
```

| 状态 | 画面                             | 规则                                                                        |
| ---- | -------------------------------- | --------------------------------------------------------------------------- |
| 抽色 | 黑白线稿，墨渍覆盖地面，天空发灰 | 据点活动，不能还色；未探索时不加载敌人                                      |
| 清理 | 仍是黑白，可还色                 | 颜色被相邻抽色区侵蚀：表面逐个褪回黑白，每 10 分钟约 10% 的表面             |
| 有色 | 色彩回来，天空转蓝               | 有色率 ≥ 70% 且有特殊诉求的居民房屋按要求完成；居民出现，画室开门，不再侵蚀 |
| 繁荣 | 招牌灯光、音乐分层               | 所有诉求完成；画室每 5 分钟产出 1 颜料；安全区、复活点                      |

**有色率** = 有颜色的表面（原色或涂鸦） / 区块总表面。

城的难度由它在野外的位置决定：离教学城越远，初始墨污越深、据点越强、墨潮越频繁。

### 4.2 墨潮

- 与抽色区相邻的"清理 / 有色"区块每 8–12 分钟触发一次：一道灰色的波从抽色一侧扫过来，6–10 名敌人随波涌入，持续 90 秒。波扫过的表面颜色被抽走，整条街在眼前变成铅笔线稿；杀掉敌人波就退。
- 守住：有色率不低于 50%，奖励颜料；失守：退回"清理"，有色率归 30%。
- 同一时间只有一处，提前 30 秒在 HUD 和地平线预警。繁荣区免疫；全城无抽色区后停止。
- 单人时间隔放宽到 15 分钟、人数减半。

### 4.3 通关

城内所有区块达到"有色"即通关：封面截图进世界列表，里程碑属性点，城门变成传送点，周围野外恢复颜色。之后可以继续完成剩余诉求把每个区块推到繁荣。

## 5. 还色

### 5.1 原色与当前色

每个表面（一面墙、一扇门、一块屋顶、一段地面）在城市骨架里记一个**原色**，创建时定死，不变。状态层只记每个表面的**当前值**：

```text
0      = 抽色（黑白）
1      = 原色
2 + n  = 涂鸦成调色板第 n 色
```

每区块一个字节数组。状态变更只有三种补丁：`drain`（墨潮和侵蚀，置 0）、`restore`（修复，置 1）、`paint`（涂鸦，置 2 + n）。

城市的原色是 AI 的配色方案（AI 失败时是模板的默认配色）。玩家修复的过程就是把 AI 的设计一块块揭开；涂鸦则是玩家覆盖它。

### 5.2 笔刷的两种模式

| 模式 | 做什么                         | 消耗             | 面向             |
| ---- | ------------------------------ | ---------------- | ---------------- |
| 修复 | 对准表面，恢复原色，不用选颜色 | 通用颜料 1       | 所有人，默认路径 |
| 涂鸦 | 自己选颜色喷上去，覆盖原色     | 对应颜色的颜料 1 | 想发挥的人       |

- 笔刷是工具槽里的一件工具（见第 8 节）。持笔刷时不能攻击，可以移动、跳跃、钩索。右键切换模式，滚轮选涂鸦颜色。
- 准星对准 ≤ 6 米的表面按住左键，1 秒涂满。大表面（屋顶、整面外墙）消耗 2。
- 涂鸦过的表面也可以再修复回原色；修复过的也可以再涂鸦。
- 不做自由笔触。

### 5.3 颜色

- 修复用**通用颜料**，不分颜色；涂鸦用**彩色颜料**，按调色板分 12 种。
- 初始调色板 4 色；全部 12 色。新颜色藏在**野外**：遗迹、山顶、森林深处、特定花田。首次到达给一支"蜡笔"，永久加入角色调色板，跨世界保留。
- 没有"用错颜色"：任何颜色都算有色。只有少数有特殊诉求的居民在意颜色（见 6.1）。

### 5.4 颜料经济

```text
墨污生物（野外 / 城内据点 / 墨潮）→ 墨（5 / 名，精英 20）
墨 → 画室提炼 → 通用颜料（2 墨 = 1）
野外花田、矿脉、湖面 → 直接采到对应颜色的彩色颜料（每处每 10 分钟刷新 2–3）
繁荣区画室 → 每 5 分钟 +1 通用颜料（不在线不累积）
通用颜料 → 修复、换工具、画墨迹标记
彩色颜料 → 涂鸦、特殊诉求
```

墨和颜料属于世界（房主权威），不随角色跨世界。清一个据点的墨应够修复该区块的 40–60%，其余靠野外采集，这是进城前要在野外转一转的理由。只走修复路线的玩家不需要彩色颜料。

## 6. AI 的职责：生成"目的"，不生成"规则"

AI 是锦上添花。野外完全不用 AI；城市先由程序生成可玩的骨架，AI 填风格、名字和居民诉求；AI 失败或无密钥时用模板城，玩法不变，只是没有个性。

| AI 生成                                      | 程序控制                       |
| -------------------------------------------- | ------------------------------ |
| 城名、街区名、建筑风格参数、配色             | 道路、街块、可达性、碰撞、导航 |
| 住宅室内布局和房间用途                       | 室内几何、家具、碰撞           |
| **居民诉求**：谁住这里、要什么颜色、需要什么 | 诉求可完成性校验、奖励结算     |
| 模板工坊里的参数（见第 7 节）                | 参数范围、几何构建、校验       |

### 6.1 居民诉求

大多数居民只要"把颜色还给我"，房子修复到原色就满足，这是默认诉求，不需要 AI。每座城创建时，AI 另为每个街区的 1–2 栋住宅写一条**特殊诉求**，结构固定、文本自由：

```json
{
  "building": 2,
  "resident": "老陈",
  "want": { "kind": "recolor", "color": "blue" },
  "line": "房子原来是橙色的，但我一直想要一栋蓝房子……"
}
```

| kind      | 内容                                          | 奖励            |
| --------- | --------------------------------------------- | --------------- |
| `restore` | 把这栋房子修复到原色（默认诉求，程序生成）    | 颜料 + 经验     |
| `recolor` | 用涂鸦把这栋房子涂成居民想要的颜色            | 额外颜料 + 经验 |
| `fetch`   | 从相邻街区画室取 N 桶颜料，或从野外采指定颜色 | 新颜色或工具    |
| `clear`   | 清掉楼里的墨污（室内 2–4 名敌人）—— 第二版    | 工具            |

程序校验：颜色在 12 色内且不等于原色；`fetch` 来源存在；`clear` 只对有室内的住宅生效。校验不过的诉求丢弃，回退默认诉求，不阻塞生成。

### 6.2 住宅的用途

| 用途   | 来源               | 玩法                                             |
| ------ | ------------------ | ------------------------------------------------ |
| 居民家 | 诉求指定           | 门口任务牌；完成后居民出现在门口（首版静态模型） |
| 画室   | 每街区固定 1 栋    | 提炼颜料、领取产出、换工具                       |
| 安全屋 | 繁荣区自动获得     | 检查点、复活点                                   |
| 墨污巢 | `clear` 诉求的住宅 | 室内战斗（第二版）                               |

室内仍按需、按门口 E 触发，缓存规则不变。

## 7. 模板与 AI 创意工坊

建筑、地标、遗迹都是**带参数的程序模板**，参数全是枚举或有界范围，所以任何参数组合都能建出来、都能过校验。

```json
{
  "type": "tower",
  "floors": 6,
  "footprint": "octagon",
  "top": "spire",
  "palette": [3, 7],
  "decor": ["arch", "flag"]
}
```

首版三类模板：

| 类   | 模板             | 用途               |
| ---- | ---------------- | ------------------ |
| 地标 | 塔楼、钟楼、车站 | 城市入口，远处可见 |
| 建筑 | 住宅、商铺、仓库 | 城内街块填充       |
| 遗迹 | 石圈、断桥、碑林 | 野外藏颜色         |

**工坊**是主菜单里的一个界面：输入一句描述 → AI 输出参数 → 即时预览 → 存进模板库 `world-data/templates/`。可以导出文件和朋友交换。新建城市和野外遗迹从库里抽；库为空用内置模板。

## 8. 工具体系（替代固定职业）

不再有创建时锁定的职业。玩家带一组工具，随时切换，数字键或滚轮。现有四职业的武器和技能全部保留，技能从"职业技能"改为**挂在武器上**：拿刀就有突进斩，拿法杖就有法阵。

| 工具                                   | 来源                                   | 说明                                                    |
| -------------------------------------- | -------------------------------------- | ------------------------------------------------------- |
| 武士刀、步枪、狙击枪、榴弹炮、墨能法杖 | 初始给步枪；其余画室用颜料换或诉求奖励 | 现有模型、手感、技能原样                                |
| 笔刷（三档：基础 / 远距 / 双面）       | 初始 + 画室升级                        | 修复 / 涂鸦两种模式                                     |
| 纸飞机                                 | 教学城通关                             | 高处起跳展开，缓慢下降可转向；野外主要移动手段          |
| 墨马                                   | 第一座城通关                           | 野外地面速度 2.5 倍，不能进城、不能战斗，被打一下散成墨 |
| 墨迹标记                               | 消耗 10 颜料                           | 野外放置传送点，每世界最多 3 个                         |

属性保留生命、武器强度、技能强度、防护四项和原公式，去掉职业基础差异。PVP 变成"带什么工具进场"，现有击杀赛规则不变。

## 9. 成长

- 等级 1–10，经验来源：还色一个表面 1、区块有色 60、守住墨潮 40、诉求完成 25–60、通关一座城 150、首次到达遗迹 25。
- **属性点改为里程碑**，取消概率和保底：

| 里程碑                               | 属性点      |
| ------------------------------------ | ----------- |
| 第一次区块有色                       | 1           |
| 每座城第 5 / 10 / 15 / 20 个区块有色 | 各 1        |
| 第一次守住墨潮                       | 1           |
| 集齐 12 色                           | 2           |
| 通关一座城                           | 3（每座城） |

- 横向成长是调色板和工具。
- 跨世界：调色板、里程碑、等级跟角色走；墨、颜料、工具留在世界。

## 10. 死亡

掉落身上一半的墨，留在原地可捡回；不掉颜料、工具、调色板。野外在最近的墨迹标记或城门复活，城内在安全屋或城门复活。

## 11. 多人与 PVP

- 合作：墨潮是主要压力；`fetch` 诉求让人分头跑；有色率是团队指标。修复和涂鸦的人在同一座城里互不干扰。
- 工具差异保留配合：刀和炮守墨潮，狙清据点，法阵减速保护表面。
- PVP 保留击杀赛。可选**抢色赛**：两队在一个区块各用自己的颜色涂鸦，时限内面积高者胜；复用笔刷、颜料、状态层。

## 12. 砍掉的

- 固定职业与创建时锁定
- 属性点 5% 概率与保底
- 每区块一次 AI 调用、无密钥不能生成
- "供电站 → 开放第一栋住宅"固定模板（功能并入画室）
- 住宅室内不生成敌人或交互的限制
- 旧存档兼容

## 13. 首版范围

**做：**

1. 野外：4 个群系的噪声地形（台地式）、植被模板、墨污生物、颜料来源、遗迹
2. 教学城（固定模板）
3. 城市副本：道路生长、街块、模板建筑与原色、AI 配色与诉求（`recolor` / `fetch`）、落盘与同城切换
4. 区块状态机、墨潮抽色、通关、野外颜色派生
5. 工具体系：五种武器 + 三档笔刷（修复 / 涂鸦） + 纸飞机 + 墨迹标记
6. 按表面还色、三种补丁、12 色、野外取色
7. 颜料经济、画室
8. 里程碑属性点、经验表
9. 内置模板库（地标 3、建筑 3、遗迹 3）

**第二版：**

- 墨马
- 繁荣状态产出与安全屋
- `clear` 诉求与室内战斗
- AI 创意工坊界面
- 可走动的 NPC
- 抢色赛

## 14. 待验证参数

| 参数         | 首版值                    | 验证方法                            |
| ------------ | ------------------------- | ----------------------------------- |
| 城规模       | 5×5                       | 一座城通关 1.5–2 小时；过长缩 4×4   |
| 城市入口密度 | 野外每 6–8 区块一个       | 出一座城视距内能看见下一座的地标    |
| 区块总表面数 | 150–300                   | 生成 10 个街块统计                  |
| 还色一个表面 | 1 秒                      | 独自修复一个区块 4–6 分钟           |
| 侵蚀速度     | 10% 表面 / 10 分钟        | 两人 30 分钟不被逼回超过一次        |
| 墨潮间隔     | 8–12 分钟                 | 一座城 12–18 次墨潮                 |
| 野外颜料刷新 | 每处 10 分钟 2–3          | 进城前 5 分钟采集够涂一个区块的 40% |
| 纸飞机滑翔比 | 1 : 4（降 1 米前进 4 米） | 从山地台地顶能滑到相邻区块          |

## 15. 开放问题

- 居民是否需要可走动的 NPC：首版任务牌 + 静态模型，试玩后定。
- 野外墨污生物的种类：先复用现有 inkblot / eraser / flyer，按群系换配色和数值，不加新 AI。
- 职业被舍弃后，旧设计里的职业装置（改变技能的稀有装备）是否保留为"武器配件"：倾向保留，第二版。
