# 重彩 V3 玩法设计

一句话：**第一人称的联机大世界。玩家在一个无限的手绘世界里探索、打怪、互相 PK；被墨潮抽干的城市是副本，组队进去把颜色还回来。**

本稿替代 V2（V2 全文在 git 历史 `ccbf616` 的 `docs/game-design.md`）。V2 已经做完的系统大多保留，只是换了位置：城市、颜料、墨潮从"主线"变成"副本"，主舞台换成野外。世界生成算法见 [world-generation.md](world-generation.md)，代码分层见 [architecture.md](architecture.md)。

## 1. 方向

| 支柱       | 说的是什么                                                       |
| ---------- | ---------------------------------------------------------------- |
| 大世界探索 | 野外是主舞台：远处看得见目标，走过去有东西拿，越灰的地方越危险   |
| 玩家 PK    | 野外默认可以互相攻击；有规则防止欺负新人和无休止的追杀           |
| 打击感     | 每一下命中都要听得见、看得见、手上感觉得到；联机延迟不能吃掉手感 |
| 副本       | 城市是组队 PvE 副本：清据点、还色、守墨潮，奖励带回野外          |

### 1.1 不做

前几轮讨论过、这一版明确不做的：

- 觉醒技、色彩槽、套装、时装、配件品质、技能点改技能
- 隐藏任务、史诗任务链、NPC 盟友、驻地、称号、纪录与评分
- 部位破坏、浮空连击、霸体精英、机制型 BOSS
- AI 起名、配色、居民心愿文案和创意工坊（城市用程序生成，够用）
- 疲劳值、每日上限、随机掉落装备、强化
- 国战、拍卖行、公会

要加回任何一条，先回答一个问题：它让探索、PK 或打击感变好了吗？

## 2. 世界结构

```text
野外（无限，种子生成，主舞台，可以 PK）
  ├── 出生点（安全区）
  ├── 城市入口塔楼 ──► 城市副本（组队，PvE，不能 PK）
  ├── 已恢复的城市塔楼周围（安全区，传送点）
  ├── 遗迹（藏蜡笔）
  ├── 颜料点（采集，可争夺）
  └── 野外墨怪（越灰越多）
```

| 区域       | PK       | 墨怪           | 能做什么                             |
| ---------- | -------- | -------------- | ------------------------------------ |
| 安全区     | 不能     | 不进来         | 复活、传送、画室提炼颜料、组队、约战 |
| 野外       | 可以     | 按灰度刷       | 探索、采集、打怪、PK、放墨迹标记     |
| 城市副本内 | 不能     | 据点、墨潮带来 | 还色、守墨潮、恢复城市               |
| 约战圈     | 只限双方 | 不进来         | 一对一或小队对打，不掉落、不红名     |

野外地形、群系、树、河、城市入口、遗迹的生成都不变。

## 3. 探索

第一人称探索靠三件事：**看得见目标、走得过去、到了有回报。**

### 3.1 看得见

- 城市塔楼、遗迹、颜料点从远处就能看见（已有）。
- 屏幕顶部一条**指南针**：显示方向，以及视距内看见过的塔楼、遗迹、墨迹标记和队友。
- 按 M 打开**简易地图**：走过的区块、发现过的地点、自己的标记和队友。没去过的地方是空白的纸。

### 3.2 走得过去

沿用现有的移动能力，不再加新的：

| 能力     | 来源             | 说明                                 |
| -------- | ---------------- | ------------------------------------ |
| 冲刺     | 初始             | Shift                                |
| 二段跳   | 初始             | 空格                                 |
| 纸飞机   | 第一次恢复城市   | 空中按住空格滑翔，滑翔比约 1:4       |
| 墨迹标记 | 第一次恢复城市   | 野外最多 3 个，加入传送环            |
| 传送     | 恢复过两座城以后 | 已恢复的城和墨迹标记之间，红名不能用 |

### 3.3 到了有回报

| 发现                 | 回报                                |
| -------------------- | ----------------------------------- |
| 第一次到一座城市入口 | 经验，地图标记                      |
| 遗迹                 | 经验，一支新颜色的蜡笔              |
| 颜料点               | 颜料（10 分钟后长回来），谁先到谁拿 |
| 野外墨怪             | 墨和经验，15 分钟后回来             |
| 越灰的区域           | 墨怪更多，颜料点产出更多            |

**蜡笔是唯一的收集品。**一支蜡笔解锁一种颜色，可以用在两个地方：涂鸦笔刷，以及**自己角色的强调色**（见第 8 节）。在 PK 里别人能直接看到你走过多远。

## 4. 副本：城市

城市玩法基本保持 V2 的做法，只是改成副本。

- **进入**：在城市塔楼门口按 E。队伍一起进，所有人进的是同一座城。城市的进度（每个表面的颜色）属于世界，所有人共享。
- **目标**：清据点 → 把街区涂到有色 → 守住墨潮 → 全城有色即恢复。
- **规则沿用**：街区状态（抽色 / 清理中 / 有色 / 繁荣）、侵蚀、墨潮、墨帘推回、据点没清空不能上色，全部照旧。
- **不能 PK**：副本里队友之间不互相伤害，非队友不能进同一座城的副本（见 7.4）。
- **恢复以后**：塔楼周围变成安全区和传送点，周围野外重新上色，墨怪不再出现。

### 4.1 简化颜料

V2 的颜料分通用颜料和 12 种彩色颜料。V3 合并：

```text
墨（唯一货币）：打怪、颜料点、副本奖励；死亡掉一半，PK 可以抢
墨 → 画室提炼 → 颜料（副本里的耗材）
颜料：修复和涂鸦都花它；涂鸦能选的颜色由蜡笔决定
```

野外颜料点直接给颜料。彩色颜料和"首采解锁颜色"取消，颜色只由遗迹里的蜡笔解锁。

### 4.2 副本奖励

| 事件         | 奖励                           |
| ------------ | ------------------------------ |
| 一个街区有色 | 经验                           |
| 守住墨潮     | 墨、颜料、经验                 |
| 恢复一座城   | 大量墨和经验、属性点、武器解锁 |

## 5. 战斗与打击感

PvE 和 PvP 用同一套命中规则。墨怪和玩家都是"可被射中的目标"（现在的 `ctx.combat` 已经是这个结构）。

### 5.1 打击感清单

按"谁感觉到"分三类。每一条都是表现层：**只听事件，不改伤害和规则**（和现在的声音、特效一样）。

**开火的人：**

| 反馈     | 做法                                                       | 现状 |
| -------- | ---------------------------------------------------------- | ---- |
| 命中标记 | 准星上闪一个 ✕，0.15 秒；爆头是另一种颜色和声音            | 新增 |
| 击杀标记 | 更大的 ✕ 加一声重音                                        | 新增 |
| 顿帧     | 近战和榴弹直接命中时，自己的武器模型和目标的动作停 50 毫秒 | 新增 |
| 伤害数字 | 打中飘数字，大伤害金色，击杀红色                           | 已有 |
| 后坐     | 枪口上跳、连射叠加、慢慢回正                               | 已有 |
| 弹道     | 亮色短弹道从枪口飞出，打墙有墨屑                           | 已有 |

**被打的人：**

| 反馈     | 做法                                                      | 现状 |
| -------- | --------------------------------------------------------- | ---- |
| 方向     | 屏幕中央的红箭头指向攻击来向                              | 已有 |
| 震屏     | 按伤害大小                                                | 已有 |
| 准星偏移 | 被狙击枪或榴弹打中，视角向上弹一下（约 1.5°），0.2 秒回正 | 新增 |
| 受击减速 | 被近战或榴弹打中，移动速度降 30%，0.25 秒                 | 新增 |
| 屏幕边缘 | 低血量时边缘泛墨色                                        | 新增 |

**旁边看的人：**

| 反馈 | 做法                                 | 现状         |
| ---- | ------------------------------------ | ------------ |
| 受击 | 角色模型向受击方向后仰（墨怪已经有） | 玩家模型新增 |
| 击退 | 近战和榴弹把目标推开 0.5–1.5 米      | 新增         |
| 溅墨 | 命中处溅出墨点                       | 已有         |
| 倒下 | 玩家倒下时身体化成墨，墨袋留在原地   | 新增         |

### 5.2 破招（只对墨怪）

墨怪出手前有 0.25 秒蓄力（墨团举手、墨吐后仰）。蓄力时被打中，这次攻击取消，墨怪硬直 0.5 秒，伤害 ×1.3，飘一个"破招"字样。玩家之间不做破招，因为玩家开火没有前摇。

### 5.3 命中部位

玩家有**头**和**身体**两个命中盒，所有角色共用一套（见 8.1）。爆头伤害 ×1.5，狙击枪 ×2。墨怪暂时不分部位。

### 5.4 联机下的手感

延迟会吃掉手感，所以按下面的规则拆分本地表现和服务器判定：

- **命中标记、开火声、后坐、弹道**：本地立刻出，不等服务器。
- **伤害数字、击杀标记、对方倒下**：服务器确认后出。正常网络下，从开火到出数字的延迟在一个往返之内（局域网 < 30 毫秒）。
- **服务器做延迟补偿**：判定命中时，把其他玩家的位置倒回到开火者屏幕上看到的那一刻，最多倒回 200 毫秒。这样打得准的人在服务器上也算打中。
- **顿帧只在本地**：不影响服务器的模拟时间。

## 6. PvP 与 PK

### 6.1 区域

- **安全区**：出生点周围、已恢复城市的塔楼周围 40 米内、所有副本内。这里玩家之间打不到。
- **野外**：其他地方都可以 PK。

### 6.2 规则

只有五条：

1. **新人保护**：3 级以前不能攻击玩家，也不会被玩家攻击。升到 3 级时提示一次。
2. **红名**：攻击一个没有先攻击你、也不是红名的玩家，你会红名 10 分钟（再次攻击就重新计时）。红名的人名字是红色，**不能传送，死亡掉落全部墨**。打红名的人不会变红名。
3. **死亡掉落**：倒下时掉一半墨，留在原地一个墨袋，**谁都能捡**。等级、武器、蜡笔从不掉落。
4. **复活**：在最近的安全区复活，3 秒无敌；无敌期间开火就提前结束。
5. **约战**：在安全区对着另一名玩家按 F 发起邀请，对方接受后 3 秒倒计时，两人周围出现 30 米的约战圈。圈里只有双方能互相伤害，不掉落、不红名，倒下或出圈就算输，结束后回满血。小队约战规则相同，双方各 2–4 人。

### 6.3 平衡

- 等级最高 10 级。满级对 1 级的差距主要来自生命和武器强度，大约让击杀时间差 1.5 倍，不会到碾压的程度。
- 约战用双方当前的属性，不做统一。
- **玩家伤害单独一套数**：PvE 的伤害对墨怪调过，直接打玩家太快。每把武器在 `content/weapons.ts` 加一个 `pvp` 字段，目标是 100 生命的玩家：

| 武器     | 打玩家伤害 | 爆头 | 目标击杀时间（全身中）   |
| -------- | ---------- | ---- | ------------------------ |
| 步枪     | 9          | ×1.5 | 约 1.2 秒                |
| 武士刀   | 28         | —    | 4 刀，约 1.3 秒          |
| 狙击枪   | 55         | ×2   | 2 枪身体，或 1 枪爆头    |
| 榴弹炮   | 40（直击） | —    | 3 发直击，溅射按距离衰减 |
| 墨能法杖 | 18         | ×1.5 | 约 2.5 秒                |

技能对玩家也减弱：突进斩伤害 ×0.6；战术闪避的护盾 40 → 25；法阵每跳伤害减半。这些都是初值，试玩后再调。

## 7. 联机

### 7.1 规模和形态

- 一个世界 2–8 人，好友局域网或者公网直连。
- 一台机器运行**世界服务器**（Node，`npm run server`），所有人（包括开服的人）都用浏览器连进来。没有房主特权，开服的人不占便宜。
- 存档在服务器上。现在的 `WorldStore` 接口不变，换成服务器实现。

### 7.2 服务器权威

| 服务器决定                   | 客户端负责                        |
| ---------------------------- | --------------------------------- |
| 伤害、死亡、掉落、红名、约战 | 输入、自己移动的预测              |
| 墨怪 AI、墨潮、侵蚀          | 渲染、声音、特效、打击感          |
| 补丁（上色、采集、解锁）     | 其他玩家的插值显示（延后 100 ms） |
| 玩家位置的校验（速度、穿墙） | 命中标记的本地预测                |

- 服务器以 20 Hz 运行模拟，客户端照常按帧渲染。
- 补丁已经只带 ID，规则都在 `applyPatch` 里，所以服务器直接复用。
- **服务器跑的是现在的系统代码**：`tests/support/headless.ts` 已经证明墨潮、墨怪、战斗可以不用 WebGL 在 Node 里逐帧运行，服务器就建在这个基础上。

### 7.3 兴趣范围

服务器只把每个玩家周围已加载区块（现在是 Chebyshev 半径）内的玩家、墨怪和掉落发给他。

### 7.4 副本实例

- 每座城同一时间只有一个实例。第一个进去的队伍占用它，别的玩家要等这个队伍出来。
- 野外和最多两座城可以同时运行。服务器负载超了就排队。
- 组队：最多 4 人，队友在指南针和地图上显示，不能互相伤害，一起进副本。

### 7.5 作弊

这是朋友之间的游戏，只做基础校验：移动速度、射速、弹匣、射程、技能冷却都由服务器检查，超出就丢弃那次操作。

## 8. 角色造型（玩家和墨怪）

画面是手绘动画背景：没有描边，暖色日光、偏蓝的阴影，最后过一遍笔触滤镜（Kuwahara），把画面变成一笔笔颜料。角色和墨怪走同一个材质和后处理，所以造型要为这套渲染设计。

以前的墨怪是按线稿画风做的（黑色多面体和火柴人，[images/monsters.jpg](images/monsters.jpg)），放进现在的画面里有两个问题：四肢只有 0.04–0.09 米粗，被笔触滤镜一抹就没了；多面体的硬棱在笔触下变成碎块。所以墨怪按本节重做了（2026-11-16）。

概念图：[images/players.svg](images/players.svg)（玩家）、[images/monsters.svg](images/monsters.svg)（墨怪）

### 8.1 共同规则

| 规则                                                 | 原因                                                 |
| ---------------------------------------------------- | ---------------------------------------------------- |
| 大块形体，靠剪影和色块来读，不靠线                   | 没有描边，细节会被笔触滤镜抹平                       |
| 最小部件 0.12 米；眼睛、带子这类只在近处看的细节例外 | 20 米外 0.05 米的东西不到一个像素                    |
| 圆润、略胖，头身比约 1:6                             | 和树冠、坡屋顶一样柔和；头大一点，远处也认得出是人   |
| 平滑法线（细分的圆块和胶囊），不留硬棱               | 多面体的棱面在笔触滤镜下会变成乱的碎块               |
| 颜色只从调色板取                                     | 材质按调色板编号上色，日光、阴影、昼夜、抽色自动对上 |
| 投下太阳阴影                                         | 和房子、树一样落在地上                               |
| 靠二次摆动出生气（围巾、头发、披风、墨滴），不靠细节 | 手绘动画的生气来自跟随动作                           |

调色板追加了浅、暖、深三种肤色（只能加在末尾）。墨的湿亮不用新颜色：渲染器对 `solid` 的墨本来就加了一道随光的高光。

### 8.2 玩家和墨怪怎么区分

|      | 玩家                                       | 墨怪                             |
| ---- | ------------------------------------------ | -------------------------------- |
| 明暗 | 亮：米白、肤色、暖色布料                   | 暗：蓝黑色的湿墨                 |
| 表面 | 布料，哑光                                 | 湿亮，顶上一道高光，底下往下滴   |
| 颜色 | 自己选的强调色；**始终是全彩**，抽色区不褪 | 抢来的颜色在身体里发亮           |
| 形体 | 人形，站得直，形体不变                     | 不稳定：会塌、会拉长、会长出手臂 |

玩家在抽色区也保持全彩（用材质里"始终有色"的标记，现在拾取物在用）。颜色是玩家带进这个世界的，这既是故事，也让 PK 时在灰色区域里一眼就看得到人。

### 8.3 玩家角色

- **外观不影响命中**：所有角色共用一套命中盒。身体是 0.7 × 1.42 × 0.7 米（宽度和物理碰撞的 `halfWidth` 0.35 一致），头是 0.36 米立方，中心在 1.62 米（眼睛高度 1.65）。帽檐、围巾、披风、马尾不算命中。
- **剪影靠头部区分**：PK 时远处只看得清轮廓，所以四个角色的区别集中在头和肩上。身高都在 1.75–1.85 米，不做特别矮小、容易躲的角色。
- **强调色涂在大块上**：没有描边，小面积的颜色远处看不见，所以强调色涂在帽子、兜帽、披风这类大块上。
- **脸**：两只深色的椭圆眼睛、淡淡的腮红，不画嘴和鼻子。脸只在近处看，远处靠帽子和发型认人。
- **可以选的只有颜色**：肤色 3 种、发色 4 种（炭灰、栗棕、沙土、米白）、强调色（已解锁的蜡笔）。形体和命中盒不变。
- **技术上复用墨怪的骨架**：`monster-figure.ts` 的"关节 + 圆块 + 肢体"骨架和两个实例化网格照用，抽成共享的 figure 模块，角色数据放 `content/characters.ts`。肢体从细棍换成胶囊，圆块提高细分。

| 角色   | 形体                                                   | 固定配色                             | 强调色       | 二次摆动         |
| ------ | ------------------------------------------------------ | ------------------------------------ | ------------ | ---------------- |
| 信使   | 中等身材，短外套，斜挎大邮包，贝雷帽，背后折着纸飞机   | 米白外套，栗棕邮包和靴子，炭灰裤子   | 贝雷帽、围巾 | 长围巾           |

### 8.4 玩家动作

别人看你的第三人称动作，按优先级：

| 类别 | 动作                                                                               |
| ---- | ---------------------------------------------------------------------------------- |
| 移动 | 待机呼吸、走、跑（按速度混合）、冲刺、跳、二段跳、下落、落地、滑翔（双手举纸飞机） |
| 瞄准 | **上半身跟着视角俯仰**，别人能看出你在看哪里；开镜时贴脸                           |
| 武器 | 步枪和法杖双手持，狙击枪开镜，榴弹炮扛肩，武士刀单手；每种有开火或挥砍、换弹       |
| 技能 | 闪避（侧滑）、突进斩（前冲拖影）、蓄力炮击（下蹲蓄力）、法阵（举杖下按）           |
| 笔刷 | 手臂伸出来回涂                                                                     |
| 受击 | 按方向后仰；被近战或榴弹打中时更明显，带击退                                       |
| 倒下 | 墨从脚下往上染黑全身，化成一摊，留下墨袋                                           |
| 复活 | 先是一个半透明的灰影，0.5 秒内填上颜色                                             |

动作风格按手绘动画来：出手前有预备动作，停下时围巾、头发、披风还会多摆一下，落地时身体往下压一点再弹回来。

### 8.5 名字和血条

- 名字悬在头顶，40 米内可见，被墙挡住就隐藏。红名是红色，队友是绿色。
- 敌对玩家的血条只在被你打中后显示 3 秒，和墨怪一样。

### 8.6 墨怪

**墨是一种活的液体，不是黑色的人。**平时它塌成一堆，走动时拉长，要攻击了才长出手臂。抢来的颜色在身体里像灯一样亮着，这是墨怪身上唯一的亮色，**也是攻击预警**：要出手的时候，形体变大、颜色变亮，20–30 米外也看得出来，比看细小的手臂动作可靠得多，打断和破招（5.2 节）都靠这个。

|                           | 墨团（近战）                                                                                 | 墨吐（远程）                                        |
| ------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| 体型                      | 约 1.2 米高、1 米宽的一团，像一只装满墨的大口袋，两只短粗的脚                                | 约 1.7 米高，细长的水滴形身体，长脖子，喉咙上一个囊 |
| 平时                      | 往下坍，走路时左右晃，脚下滴墨                                                               | 弓着背，脖子往前伸，身体随步子左右摆                |
| 抢来的颜色                | 在肚子里慢慢旋转；两只眼睛发亮                                                               | 积在喉囊里；两只眼睛发亮                            |
| 蓄力（0.25 秒，规则不变） | 身体往上拉长到约 1.6 米，两侧长出两条粗手臂举过头，颜色变亮                                  | 喉囊鼓起来、越来越亮，脖子往后仰                    |
| 出手                      | 两条手臂砸下，砸完缩回身体                                                                   | 头往前一甩，吐出一团带颜色的墨                      |
| 受击                      | 被打中的那一侧凹进去，再弹回来，溅出墨点                                                     | 整个身体弯向一边再弹回                              |
| 倒下                      | 摊成一片墨，抢来的颜色像颜料一样飘出来，落在附近的墙和地上（沿用现在"打倒墨怪就还色"的规则） | 同左                                                |

- **命中盒不跟着形体变**：蓄力时拉长只是外观，命中盒还是 `content/enemies.ts` 里的尺寸，不然打断的时机会变得难以判断。
- **墨的质感**：底色是现有的 `ink`（渲染器给它加湿亮的高光），底部挂几颗会滑下、落下再长回来的墨滴。
- **骨架**：沿用现在的骨架。墨团的手臂平时缩到零，蓄力时伸出来；身体的拉长和压扁用躯干的缩放来做。

## 9. 成长

保留 V2 的简单版本：

- 等级 1–10，经验来自探索发现、打怪、副本进度、PK 击杀（击杀玩家给少量经验，同一人 10 分钟内只算一次）。
- 属性点来自里程碑，四项属性（生命、武器强度、技能强度、防护）和公式都不变。
- 武器解锁：步枪初始；武士刀、狙击枪、榴弹炮、墨能法杖随副本进度和等级解锁（沿用现在的条件）。
- 等级、属性、武器、蜡笔属于角色，存在服务器上。墨和颜料也属于角色，死亡会掉。

## 11. 开发顺序

1. **打击感（单机就能做）**：命中标记、击杀标记、顿帧、破招、准星偏移、受击减速、击退。这些只是在现有事件上加表现，可以先在单机里调手感。
2. **角色和墨怪模型**：从 `monster-figure.ts` 抽出共享的 figure 模块，按第 8 节重做墨怪，再做四个玩家角色和第三人称动作。先在野外放几个原地动作的"木桩"角色，用来试打击感和命中盒。
3. **联机基础**：世界服务器、连接、玩家移动同步（预测 + 插值）、服务器存档、每个角色一份背包。
4. **战斗联机**：服务器判定命中、延迟补偿、玩家伤害、死亡掉落。
5. **PK 规则**：安全区、新人保护、红名、约战。
6. **副本联机**：队伍、城市实例、墨潮和墨怪由服务器运行。
7. **探索补全**：指南针、简易地图、颜料合并。

## 13. 开放问题

- 是否需要公网大服务器：现在按 8 人以内的好友服设计；要做更多人，得重新设计兴趣范围和存档。
- 副本是否允许多个队伍各开一个实例：现在一座城只有一个实例，因为城市进度是世界共享的。
- PK 击杀是否给墨以外的奖励：目前只给经验和对方掉的墨，避免专门刷人。
- 第一人称下要不要显示自己的手：现在只显示武器；有了角色模型以后，可以给第一人称加上对应角色的手和袖子。
