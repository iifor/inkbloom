# 重彩 V3 玩法设计

一句话：**第一人称的联机大世界。墨潮抽走了世界的颜色，玩家是唯一还带着颜色的人：在野外探索、互相争夺颜色，再组队进被抽干的城市，把颜色还回来。**

本稿替代 V2（V2 全文在 git 历史 `ccbf616` 的 `docs/game-design.md`）。V2 已经做完的系统大多保留，只是换了位置：城市、颜料、墨潮从"主线"变成"副本"，主舞台换成野外。世界生成见 [world-generation.md](world-generation.md)，四季与天气见 [seasons-weather.md](seasons-weather.md)，代码分层见 [architecture.md](architecture.md)。

## 1. 核心

### 1.1 主题：颜色是唯一值得争的东西

所有玩法都围着颜色转，这是重彩和别的射击游戏不一样的地方：

| 玩法 | 和颜色的关系                                                   |
| ---- | -------------------------------------------------------------- |
| 探索 | 遗迹里找到蜡笔，解锁新颜色                                     |
| PK   | 用自己的颜色涂下野外的遗迹，把它占成自己的复活点；别人来涂掉它 |
| 副本 | 把被抽干的城市涂回原色                                         |
| 外观 | 抽色区一片灰，只有玩家是全彩的；你的强调色就是你走过多远的证明 |
| 打击 | 打墨怪溅墨，打玩家溅出他的颜色                                 |

### 1.2 核心循环

```text
安全区：存墨、提炼颜料、组队
  → 出门探索：发现遗迹和城市、采颜料、打野外墨怪，背上的墨罐越来越满
  → 争夺：涂下遗迹占点，或者去抢别人的点、截别人的墨罐
  → 带着墨回安全区存起来（路上可能被截）
  → 组队进城市副本，把城市涂回颜色
  → 城市恢复：多一个安全区和传送点，周围野外变回彩色
  → 往更灰、更危险、收获更多的地方走
```

### 1.3 支柱

| 支柱       | 说的是什么                                                         |
| ---------- | ------------------------------------------------------------------ |
| 大世界探索 | 野外是主舞台：远处看得见目标，走过去有东西拿，越灰的地方越危险     |
| 玩家 PK    | 野外可以互相攻击，争的是遗迹和墨罐；有规则防止欺负新人和无休止追杀 |
| 打击感     | 每一下命中都要听得见、看得见、手上感觉得到；联机延迟不能吃掉手感   |
| 副本       | 城市是组队 PvE 副本：清据点、还色、守墨潮，奖励带回野外            |

### 1.4 单人也能玩

朋友不在线时游戏照样能推进：探索、采集、占点、野外墨潮、城市副本都可以一个人做，墨潮和墨怪按在场人数缩放。PK 是有人在的时候多出来的一层，不是推进的前提。

### 1.5 不做

要加任何新东西，先回答：**它让探索、PK 或打击感变好了吗？跟颜色有关吗？**下面这些前几轮讨论过，明确不做：

- 觉醒技、色彩槽、套装、时装、配件品质、技能点改技能
- 隐藏任务、史诗任务链、NPC 盟友、驻地、称号、纪录与评分
- 部位破坏、浮空连击、霸体精英、机制型 BOSS
- AI 起名、配色、居民心愿文案和创意工坊（城市用程序生成，够用）
- 疲劳值、每日上限、随机掉落装备、强化
- 国战、拍卖行、公会、领地税、跨服
- 用颜色当属性（比如红色加攻击）：会把涂色变成算数值，丢掉自由涂鸦的乐趣
- 掉落或抢夺蜡笔、等级、武器：收集品和成长永远不会丢

## 2. 世界

```text
野外（无限，种子生成，主舞台，可以 PK）
  ├── 出生点（安全区）
  ├── 城市入口塔楼 ──► 城市副本（组队，PvE，不能 PK）
  ├── 已恢复的城市塔楼周围（安全区，传送点）
  ├── 遗迹（藏蜡笔；可以涂成自己的颜色占领）
  ├── 颜料点（采集，谁先到谁拿）
  └── 野外墨怪（越灰越多），偶尔有野外墨潮
```

| 区域       | PK       | 墨怪           | 能做什么                               |
| ---------- | -------- | -------------- | -------------------------------------- |
| 安全区     | 不能     | 不进来         | 复活、传送、存墨、提炼颜料、组队、约战 |
| 野外       | 可以     | 按灰度刷       | 探索、采集、打怪、占点、PK、放墨迹标记 |
| 城市副本内 | 不能     | 据点、墨潮带来 | 还色、守墨潮、恢复城市                 |
| 约战圈     | 只限双方 | 不进来         | 一对一或小队对打，不掉落、不红名       |

野外地形、群系、树、河、城市入口、遗迹的生成都不变。

### 2.1 四季与天气（已完成画面和声音）

一年四季跟着世界时钟走（一季 7 天），雨、雪、雾、雷暴是随风漂过野外的天气区，站在高处能看到远处在下雨。四季和天气都是 `(种子, 世界时钟, 坐标)` 的纯函数，联机不用同步。完整设计见 [seasons-weather.md](seasons-weather.md)。

第一批让天气影响玩法的规则（服务器判定时直接调 `weatherAt`）：

| 规则                                                     | 对谁有好处                   |
| -------------------------------------------------------- | ---------------------------- |
| **风影响滑翔**：顺风飞得远，逆风飞不动；悬崖边有上升气流 | 探索：纸飞机是主要的移动方式 |
| **冬天河面结冰**，能走过去                               | 探索：季节性的捷径           |
| **夜里和雾里**，别人的名字只在 15 米内显示               | PK：伏击和躲藏               |

以后再定：雪地脚印（追踪）、雨水冲淡墨（经济）。

## 3. 探索

第一人称探索靠三件事：**看得见目标、走得过去、到了有回报。**

### 3.1 看得见

- 城市塔楼、遗迹、颜料点从远处就能看见（已有）。被占领的遗迹显示占领者的颜色，远远就知道是谁的。
- 屏幕顶部一条**指南针**：显示方向，以及看见过的塔楼、遗迹（带占领者的颜色）、墨迹标记、队友和墨潮预警。
- 按 M 打开**简易地图**：走过的区块、发现过的地点、自己的标记和队友。没去过的地方是空白的纸。

### 3.2 走得过去

沿用现有的移动能力，不再加新的：

| 能力     | 来源             | 说明                                               |
| -------- | ---------------- | -------------------------------------------------- |
| 冲刺     | 初始             | Shift                                              |
| 二段跳   | 初始             | 空格                                               |
| 纸飞机   | 第一次恢复城市   | 空中按住空格滑翔，滑翔比约 1:4，受风影响           |
| 墨迹标记 | 第一次恢复城市   | 野外最多 3 个，只有自己能用的传送点                |
| 传送     | 恢复过两座城以后 | 已恢复的城、自己占的遗迹、墨迹标记之间；红名不能用 |

### 3.3 到了有回报

| 发现                 | 回报                                |
| -------------------- | ----------------------------------- |
| 第一次到一座城市入口 | 经验，地图标记                      |
| 第一次到一处遗迹     | 经验，一支新颜色的蜡笔              |
| 颜料点               | 颜料（10 分钟后长回来），谁先到谁拿 |
| 野外墨怪             | 墨和经验，15 分钟后回来             |
| 越灰的区域           | 墨怪更多，颜料点产出更多            |

**蜡笔是唯一的收集品。**一支蜡笔解锁一种颜色，用在两个地方：涂鸦笔刷（也就是占点用的颜色），以及**自己角色的强调色**（见第 11 节）。

## 4. 墨和颜料

### 4.1 只有两种资源

V2 的通用颜料和 12 种彩色颜料合并：

```text
墨：唯一的货币。打怪、野外墨潮、副本奖励
  → 在安全区的画室提炼 → 颜料
颜料：修复、涂鸦、占点都花它；能涂哪些颜色由蜡笔决定
```

野外颜料点直接给颜料。彩色颜料和"首采解锁颜色"取消，颜色只由遗迹里的蜡笔解锁。

### 4.2 身上的墨和存着的墨

- 打怪得到的墨先装进**背上的墨罐**，这些墨还不算你的。回到任何一个安全区按 E **存起来**，才算你的，存着的墨永远不会丢。
- **墨罐看得见**：墨越多，背上的罐子越大，分四档（空、小、中、满）。别人一眼就能看出你值不值得截。
- 墨罐最多装 200 墨，满了再打怪也装不下，逼着人回去存。
- 倒下时，身上的墨掉一半，在原地留一个墨袋，**谁都能捡**；红名倒下掉全部。存着的墨、颜料、等级、武器、蜡笔都不掉。
- 颜料在安全区用存着的墨提炼。颜料随身带，不会掉。

## 5. 野外争夺：用颜色占遗迹

野外 PK 的目标。规则只用现有的笔刷和表面状态。

- **能占的地方**：野外的遗迹（石圈、断桥、碑林）。每处遗迹有 6–10 个可以涂的面。
- **怎么占**：用涂鸦笔刷把这些面涂成**自己的强调色**，一面 1 份颜料、约 1 秒。超过 60% 是你的颜色，这处遗迹就是你的（组队时算整队的）。涂的时候不能开枪，站在那里涂就是在冒险。
- **占了有什么用**：
  - 你和队友可以在这里**复活**，也可以**传送**到这里。
  - 指南针和地图上，所有人都看得到它是你的颜色。
- **抢**：别人把面涂成他的颜色，超过 60% 就换主人。不需要先把你打死，但你在旁边的话，他得先过你这关。
- **上限**：每个人（或每支队伍）最多同时占 3 处。
- **褪色**：两个游戏日（约 48 分钟）没有占领者或队友去过，颜色慢慢褪回灰色，这处遗迹回到无主状态。不在线的人不会永远占着点。
- **新人**：3 级以前也能占点，但别人不能攻击他，只能把颜色涂掉。

## 6. 野外墨潮

偶尔发生的世界事件，把分散的玩家聚到一起。

- **频率**：有玩家在野外时，每 40–60 分钟一次，从附近最灰的地方涌出来。
- **预警**：提前 60 秒，指南针上出现方向和距离。
- **会做什么**：墨帘带着 6–10 只墨怪，朝最近的被占遗迹或颜料点推。墨帘扫过的遗迹颜色被抽干，变回无主。
- **怎么守**：和城市墨潮一样，打倒墨潮带来的墨怪会让墨帘后退，对准墨帘按住左键可以把它推回去。
- **奖励**：墨潮退了以后，墨怪掉的墨散在地上，谁捡到算谁的。不设休战：可以一起守，也可以趁乱抢。
- **人数**：墨怪数量按附近玩家人数缩放，一个人也守得住。

## 7. 副本：城市

城市玩法基本保持 V2 的做法，只是改成副本。

- **进入**：在城市塔楼门口按 E。队伍一起进，所有人进的是同一座城。城市的进度（每个表面的颜色）属于世界，所有人共享。
- **目标**：清据点 → 把街区涂到有色 → 守住墨潮 → 全城有色即恢复。
- **规则沿用**：街区状态（抽色 / 清理中 / 有色 / 繁荣）、侵蚀、墨潮、墨帘推回、据点没清空不能上色、打墨怪和完成心愿直接还色，全部照旧。居民心愿保留，作为可选目标。
- **不能 PK**：副本里队友之间不互相伤害，非队友不能进同一座城的副本（见 10.4）。
- **恢复以后**：塔楼周围变成安全区和传送点，周围野外重新上色，墨怪不再出现。

| 事件         | 奖励                           |
| ------------ | ------------------------------ |
| 一个街区有色 | 经验                           |
| 守住墨潮     | 墨、颜料、经验                 |
| 恢复一座城   | 大量墨和经验、属性点、武器解锁 |

副本里得到的墨直接存入，不进墨罐：副本里不能 PK，没有被截的风险。

## 8. 战斗与打击感

PvE 和 PvP 用同一套命中规则。墨怪和玩家都是"可被射中的目标"（现在的 `ctx.combat` 已经是这个结构）。

### 8.1 打击感清单

每一条都是表现层：**只听事件，不改伤害和规则**（和现在的声音、特效一样）。

**开火的人：**

| 反馈     | 做法                                                       | 现状 |
| -------- | ---------------------------------------------------------- | ---- |
| 命中标记 | 准星上闪一个 ✕，0.15 秒；爆头是另一种颜色和声音            | 新增 |
| 击杀标记 | 更大的 ✕ 加一声重音                                        | 新增 |
| 顿帧     | 近战和榴弹直接命中时，自己的武器模型和目标的动作停 50 毫秒 | 新增 |
| 伤害数字 | 打中飘数字，大伤害金色，击杀红色                           | 已有 |
| 后坐     | 枪口上跳、连射叠加、慢慢回正                               | 已有 |
| 弹道     | 亮色短弹道从枪口飞出，打墙有墨屑                           | 已有 |

**被打的人：**

| 反馈     | 做法                                                      | 现状 |
| -------- | --------------------------------------------------------- | ---- |
| 方向     | 屏幕中央的红箭头指向攻击来向                              | 已有 |
| 震屏     | 按伤害大小                                                | 已有 |
| 准星偏移 | 被狙击枪或榴弹打中，视角向上弹一下（约 1.5°），0.2 秒回正 | 新增 |
| 受击减速 | 被近战或榴弹打中，移动速度降 30%，0.25 秒                 | 新增 |
| 屏幕边缘 | 低血量时边缘泛墨色                                        | 新增 |

**旁边看的人：**

| 反馈 | 做法                                                   | 现状               |
| ---- | ------------------------------------------------------ | ------------------ |
| 受击 | 人物向受击方向后仰                                     | 模型已有，未接玩家 |
| 击退 | 近战和榴弹把目标推开 0.5–1.5 米                        | 新增               |
| 溅色 | 打墨怪溅墨；**打玩家溅出他的强调色**，在附近地面留几秒 | 溅墨已有，溅色新增 |
| 倒下 | 玩家被墨从脚下往上吞没，化成一摊，墨袋留在原地         | 模型已有，未接玩家 |

### 8.2 破招（只对墨怪）

墨怪出手前有 0.25 秒蓄力：墨团身体拉长、长出手臂，墨吐的喉囊鼓起来变亮。蓄力时被一下至少 30 点的攻击打中，这次攻击取消，墨怪硬直 0.5 秒（不动、不出手），这一下伤害 ×1.3，飘一个"破招"字样。武士刀、狙击枪、榴弹炮、法杖都能破招，步枪单发不够，所以近身的墨团要么换武器读招，要么躲。玩家之间不做破招，因为玩家开火没有前摇。

### 8.3 命中部位

玩家有**头**和**身体**两个命中盒，所有角色共用一套（见 11.3）。爆头伤害 ×1.5，狙击枪 ×2。墨怪不分部位。

### 8.4 联机下的手感

- **命中标记、开火声、后坐、弹道**：本地立刻出，不等服务器。
- **伤害数字、击杀标记、对方倒下**：服务器确认后出，延迟在一个往返之内（局域网 < 30 毫秒）。
- **延迟补偿**：服务器判定命中时，把其他玩家的位置倒回开火者屏幕上看到的那一刻，最多倒回 200 毫秒。
- **顿帧只在本地**：不影响服务器的模拟时间。

## 9. PvP 规则

### 9.1 区域

- **安全区**：出生点周围、已恢复城市的塔楼周围 40 米内、所有副本内。玩家之间打不到。
- **野外**：其他地方都可以 PK，包括被占的遗迹。

### 9.2 规则

只有五条：

1. **新人保护**：3 级以前不能攻击玩家，也不会被玩家攻击。升到 3 级时提示一次。
2. **红名**：攻击一个没有先攻击你、也不是红名的玩家，你会红名 10 分钟（再次攻击重新计时）。红名的人名字是红色，**不能传送，倒下掉落身上全部的墨**。打红名的人不会变红名。在别人占的遗迹附近攻击它的占领者不算主动攻击（守点和抢点是正当的争夺）。
3. **倒下**：身上的墨掉一半，留下墨袋，谁都能捡（见 4.2）。
4. **复活**：在最近的安全区或自己占的遗迹复活，3 秒无敌；无敌期间开火就提前结束。
5. **约战**：在安全区对着另一名玩家按 F 发起邀请，对方接受后 3 秒倒计时，两人周围出现 30 米的约战圈。圈里只有双方能互相伤害，不掉落、不红名，倒下或出圈算输，结束后回满血。小队约战规则相同，双方各 2–4 人。

### 9.3 平衡

- 等级最高 10 级，满级对 1 级大约让击杀时间差 1.5 倍，不会到碾压的程度。约战用双方当前的属性。
- 击杀玩家给少量经验，同一人 10 分钟内只算一次，避免专门刷人。
- **打玩家的伤害单独一套数**：每把武器在 `content/weapons.ts` 加一个 `pvp` 字段，目标是 100 生命的玩家：

| 武器     | 打玩家伤害 | 爆头 | 目标击杀时间（全身中）   |
| -------- | ---------- | ---- | ------------------------ |
| 步枪     | 9          | ×1.5 | 约 1.2 秒                |
| 武士刀   | 28         | —    | 4 刀，约 1.3 秒          |
| 狙击枪   | 55         | ×2   | 2 枪身体，或 1 枪爆头    |
| 榴弹炮   | 40（直击） | —    | 3 发直击，溅射按距离衰减 |
| 墨能法杖 | 18         | ×1.5 | 约 2.5 秒                |

技能对玩家也减弱：突进斩伤害 ×0.6；战术闪避的护盾 40 → 25；法阵每跳伤害减半。都是初值，试玩后再调。

### 9.4 竞技场（已完成）

联机时专门打人的地方，先于野外 PvP 做出来，用来试打人的手感和数值。

- **在哪**：从大世界里截一块真实的野外地形（由种子定下，离出生点 1.5–3 公里，避开城镇、水和遗迹，要有起伏和树），四周一圈 4.5 米高的墨墙，摆几组石块掩体。场内永远是全彩，附近没有野外墨怪
- **怎么进**：主菜单或暂停菜单的"竞技场"，传送进场；离开时传回原来的位置。只在联机时有
- **两种玩法，一个房间**：场内的人投票"混战 / 组队"，每局开始时按多数定（平票保持上一局）。混战先到 10 杀，组队自动分红蓝两队、先到 20 杀，每局最多 5 分钟。≥2 人时 10 秒倒计时开局，结束后看 10 秒排名再开下一局
- **公平**：5 把武器全都能用、满弹；伤害用 9.3 的 `pvp` 数值，不吃成长属性；生命都是 100、不回血；倒下 3 秒后在离敌人最远的出生点起来，2 秒无敌；不掉墨、不影响世界进度
- **判定在服务器**：客户端只报"从哪、朝哪、在世界时钟几点开的火"；服务器检查出发点、射速，把目标倒回到开火人看到的位置（最多 200 毫秒），再按命中盒（11.3）、地形、掩体、树干判定。命中标记和顿帧在本地立刻出，伤害、倒下、重生等服务器说了算（8.4）
- 代码：规则 `world/arena/`（选址 `site.ts`、命中 `hits.ts`、比赛 `match.ts`），服务器 `world/net/arena-host.ts`，客户端 `systems/arena/arena-system.ts`、`shell/arena-hud.ts`，数值 `content/arena.ts`

## 10. 联机

### 10.1 规模和形态

- 一个世界最多 10 人（`npm run server -- --max 10`，可以调），好友局域网或者公网直连。
- 一台机器运行**世界服务器**（Node，`npm run server`），所有人（包括开服的人）都用浏览器连进来。没有房主特权。
- 存档在服务器上。现在的 `WorldStore` 接口不变，换成服务器实现。世界一份存档，每个角色一份。

### 10.2 服务器权威

| 服务器决定                         | 客户端负责                        |
| ---------------------------------- | --------------------------------- |
| 伤害、死亡、掉落、红名、约战、占点 | 输入、自己移动的预测              |
| 墨怪 AI、墨潮、侵蚀、世界时钟      | 渲染、声音、特效、打击感          |
| 补丁（上色、采集、存墨、解锁）     | 其他玩家的插值显示（延后 100 ms） |
| 玩家位置的校验（速度、穿墙）       | 命中标记的本地预测                |

- 服务器以 20 Hz 运行模拟，客户端照常按帧渲染。
- 补丁已经只带 ID，规则都在 `applyPatch` 里，服务器直接复用。占点是遗迹表面的涂鸦补丁，加上"谁的颜色"。
- **服务器跑的是现在的系统代码**：`tests/support/headless.ts` 已经证明墨潮、墨怪、战斗可以不用 WebGL 在 Node 里逐帧运行。
- 四季和天气是纯函数，服务器只下发世界时钟，零额外带宽。

### 10.3 兴趣范围

服务器只把每个玩家周围已加载区块内的玩家、墨怪和掉落发给他。被占遗迹的颜色和墨潮预警全图下发（量很小）。

### 10.4 副本实例和组队

- 每座城同一时间只有一个实例。第一个进去的队伍占用它，别的玩家要等这个队伍出来。
- 野外和最多两座城可以同时运行。服务器负载超了就排队。
- 组队最多 4 人：队友在指南针和地图上显示，不能互相伤害，一起进副本，共享占的遗迹。

### 10.5 作弊

朋友之间的游戏，只做基础校验：移动速度、射速、弹匣、射程、技能冷却、涂色距离由服务器检查，超出就丢弃那次操作。

## 11. 角色造型（已完成模型）

画面是手绘动画背景：没有描边，暖色日光、偏蓝的阴影，最后过一遍笔触滤镜。人物和墨怪走同一个材质和后处理，造型为这套渲染设计。模型已经做好（`systems/figures/`、`systems/combat/monster-figure.ts`），玩家模型等联机后接入；开发时 `inkbloom.lineup()` 能在镜头前看到。

概念图：[images/players.svg](images/players.svg)（玩家）、[images/monsters.svg](images/monsters.svg)（墨怪）

### 11.1 共同规则

| 规则                                                 | 原因                                               |
| ---------------------------------------------------- | -------------------------------------------------- |
| 大块形体，靠剪影和色块来读，不靠线                   | 没有描边，细节会被笔触滤镜抹平                     |
| 最小部件 0.12 米；眼睛、带子这类只在近处看的细节例外 | 20 米外 0.05 米的东西不到一个像素                  |
| 圆润、略胖，头身比约 1:6                             | 和树冠、坡屋顶一样柔和；头大一点，远处也认得出是人 |
| 平滑法线，不留硬棱                                   | 多面体的棱面在笔触滤镜下会变成乱的碎块             |
| 颜色只从调色板取                                     | 日光、阴影、昼夜、季节、抽色自动对上               |
| 靠二次摆动出生气（围巾、头发、披风、墨滴），不靠细节 | 手绘动画的生气来自跟随动作                         |

### 11.2 玩家和墨怪怎么区分

|      | 玩家                                       | 墨怪                             |
| ---- | ------------------------------------------ | -------------------------------- |
| 明暗 | 亮：米白、肤色、暖色布料                   | 暗：蓝黑色的湿墨                 |
| 表面 | 布料，哑光                                 | 湿亮，底下往下滴                 |
| 颜色 | 自己选的强调色；**始终是全彩**，抽色区不褪 | 抢来的颜色在身体里发亮           |
| 形体 | 人形，站得直，形体不变                     | 不稳定：会塌、会拉长、会长出手臂 |

### 11.3 玩家角色

- **外观不影响命中**：所有角色共用一套命中盒。身体 0.7 × 1.42 × 0.7 米，头 0.36 米立方、中心在 1.62 米。帽檐、围巾、披风、马尾不算命中。
- **剪影靠头部区分**：四个角色的区别集中在头和肩上，身高都在 1.75–1.85 米。
- **强调色涂在大块上**（帽子、兜帽、披风），远处也看得见；也是占点时涂的颜色。
- **脸**：两只深色的眼睛和腮红，只在近处看。
- **开局选角色**：第一次开始游戏前先选角色，之后主菜单和暂停菜单里都能换。选的是角色、肤色 3 种、发色 4 种、强调色（这个世界里找到的蜡笔）和名字，选的时候角色就站在菜单旁边的世界里。选择存在浏览器里，跨世界保留；联机后改存在服务器上。
- **可以选的只有颜色**：形体由角色决定，所有角色共用一套命中盒。
- **背上的墨罐**：所有角色背后挂一个随墨量变大的罐子（见 4.2），挂在固定位置，不挡角色的剪影特征。

| 角色   | 形体                                                   | 强调色       | 二次摆动         |
| ------ | ------------------------------------------------------ | ------------ | ---------------- |
| 信使   | 中等身材，短外套，斜挎大邮包，贝雷帽，背后折着纸飞机   | 贝雷帽、围巾 | 长围巾           |
| 石匠   | 宽肩圆肚，工装背带裤，挽起袖子，粗手套，带矿灯的安全帽 | 安全帽、手套 | 工具袋           |
| 学徒   | 瘦高，尖兜帽，及膝长袍，宽袖，背后一支大画笔           | 兜帽、笔头   | 长袍下摆、兜帽尖 |
| 巡林人 | 中等身材，高马尾，额头推着护目镜，短披风，长靴         | 披风         | 马尾、披风       |
| 船夫   | 宽宽的斗笠，短雨衣，肩上一卷缆绳，腰间挂着布巾         | 雨衣         | 布巾、雨衣下摆   |
| 园丁   | 插着花的大草帽，长围裙，一条垂在肩上的辫子             | 围裙、帽带   | 辫子、围裙       |

### 11.4 动作

| 类别 | 动作                                                                   | 现状   |
| ---- | ---------------------------------------------------------------------- | ------ |
| 移动 | 待机、走、跑、跳、下落、滑翔（双手举纸飞机）                           | 已完成 |
| 瞄准 | 上半身跟着视角俯仰，别人能看出你在看哪里                               | 已完成 |

### 11.5 墨怪

**墨是一种活的液体，不是黑色的人。**平时塌成一堆，走动时拉长，要攻击了才长出手臂。抢来的颜色在身体里发亮，蓄力时变大变亮，这就是攻击预警（8.2）。

|      | 墨团（近战）                                     | 墨吐（远程）                                |
| ---- | ------------------------------------------------ | ------------------------------------------- |
| 体型 | 约 1.2 米高的一袋墨，两只短脚                    | 约 1.7 米高的细长水滴，长脖子，喉咙上一个囊 |
| 颜色 | 在肚子里旋转，眼睛发亮                           | 积在喉囊里，眼睛发亮                        |
| 蓄力 | 身体拉长到约 1.6 米，两侧长出粗手臂举过头        | 喉囊鼓起来、越来越亮，脖子往后仰            |
| 倒下 | 摊成一片墨，颜色飘出来落在附近的墙和地上（还色） | 同左                                        |

命中盒不跟着形体变，打断的时机才好判断。

### 11.6 名字和血条

- 名字悬在头顶，40 米内可见（夜里和雾里 15 米），被墙挡住就隐藏。红名是红色，队友是绿色。
- 敌对玩家的血条只在被你打中后显示 3 秒，和墨怪一样。

## 12. 成长

- 等级 1–10，经验来自探索发现、打怪、副本进度、守野外墨潮、PK 击杀。
- 属性点来自里程碑，四项属性（生命、武器强度、技能强度、防护）和公式不变。
- 武器解锁：步枪初始；武士刀、狙击枪、榴弹炮、墨能法杖随副本进度和等级解锁（沿用现在的条件）。
- 等级、属性、武器、蜡笔、存着的墨、颜料属于角色，存在服务器上。

## 14. 开发顺序

分三个里程碑。每个里程碑结束时都要能玩，玩过觉得对了再进下一个。

**里程碑 A：单机手感（不需要联机）**

1. 打击感：命中和击杀标记、顿帧、破招、准星偏移、受击减速、击退。
2. 资源改造：颜料合并、墨分"身上"和"存着"、墨罐上限。
3. 占遗迹：遗迹的面可以涂成自己的颜色，占了能复活和传送，会褪色。单机时就是给自己建复活点。
4. 天气玩法：风影响滑翔、冬天河面结冰。

**里程碑 B：垂直切片（2 个人）**

5. 世界服务器、连接、移动同步（预测 + 插值）、服务器存档、每个角色一份背包。
6. 显示其他玩家：接上角色模型、名字、背上的墨罐，加持武器和涂色的动作。
7. 战斗联机：服务器判定、延迟补偿、`pvp` 伤害、墨袋、溅色。
8. 占点联机、安全区、新人保护。
9. 一座城市副本两人一起打。

到这里两个人已经能完整体验：一起探索、互相抢点和墨罐、一起打副本。先玩这个版本，决定后面的数值和规则。

**里程碑 C：铺开（最多 10 人）**

10. 红名、约战、组队（4 人）。
11. 野外墨潮。
12. 指南针、简易地图、夜里和雾里的名字显示。
13. 副本实例排队、服务器负载。

## 16. 开放问题

- 占点要不要再多一个好处（比如附近的颜料点长得快）：先只给复活和传送，试玩后看抢点的动力够不够。
- 城市恢复后的塔楼能不能也被占：现在是固定的安全区；如果野外的争夺不够，可以考虑。
- 副本是否允许多个队伍各开一个实例：现在一座城只有一个实例，因为城市进度是世界共享的。
- 是否需要公网大服务器：现在按 10 人以内的好友服设计。
- 第一人称下要不要显示自己的手：现在只显示武器；有了角色模型以后，可以加上对应角色的手和袖子。
