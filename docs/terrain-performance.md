# 地形性能记录（2026-11-19）

在项目根目录运行 `npx vite-node scripts/benchmark-terrain.ts`。
固定 seed 4242、地形版本 2、位置 (-1200, -600)，每次使用新的世界实例，连续测三轮取中位数。
脚本开启 Node CPU profiler，所以这些数字用于同环境对比，不代表玩家帧率。

| 工作量                       |  优化前 | 优化后 |
| ---------------------------- | ------: | -----: |
| 292 块远景地形的生成         | 1622 ms | 941 ms |
| 九个完整野外区块的数据生成   | 1166 ms | 873 ms |
| 已加载远景的 3000 次原地更新 |   53 ms |  <1 ms |

优化前后三轮的地形顶点、法线、颜色及完整区块数据 SHA-256 均相同：
`aa0fb8b372609051ed219448b80c979b9289bca569a845e30a10cb486023912f`。

主要改动：跳过混合权重为零的旧地形噪声；限定湖泊和支流查询范围；缓存精确地形格点和河道采样；静止且详细区块集合未变时跳过远景重算。缓存有容量上限，非格点坐标不量化。

野外流式加载也分步生成数据和预热道路，每行地形采样、植被放置以及各组地标之间可让出主线程。同步生成接口保留，玩家立即落地所需的区块仍会同步完成。

浏览器以八次 64 m 位移、每段 30 个模拟帧检查流式加载：最终中位数 4.2 ms、P95 20.5 ms，首次冷加载最大 1146 ms。该检查使用调试步进，不含完整 GPU 呈现和屏幕刷新，不能当作前台 FPS；首次进入陌生区域的长帧仍未解决。

验证：56 个测试文件、468 个测试通过；生产构建通过，仍有主包大于 500 kB 的体积提示。
