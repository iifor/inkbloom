# 免费环境音接入记录

2026 年 11 月 26 日，按“直接使用 AiSHA、尽量免费”的要求，已接入 **4 项免费素材**，本次费用 **0 元**。M01～M07 继续使用此前提供的音乐文件。

## 已接入

四项均来自 SoundBits 的 [SOME OF MANY (free)](https://aishasound.com/public-libraries/111)。

| 编号 | 用途             | 循环时长 | 当前游戏文件                                    |
| ---- | ---------------- | -------- | ----------------------------------------------- |
| A02  | 开阔地鸟鸣与虫声 | 60 秒    | `public/sounds/ambience/aisha-meadow-birds.ogg` |
| A05  | 户外风声         | 60 秒    | `public/sounds/ambience/aisha-wind.ogg`         |
| A06  | 滑翔迎面风声     | 6 秒     | `public/sounds/ambience/aisha-glide-wind.ogg`   |
| A09  | 墨潮低频轰鸣     | 50 秒    | `public/sounds/ambience/aisha-ink-rumble.ogg`   |

A02 是包含鸟、虫、乌鸦、公鸡和树叶声的乡野混合底声，不是单独的鸟叫。它沿用开阔地环境声的位置、季节、昼夜和雨天衰减规则；旧鸟鸣保存在 `art/audio/legacy-ambience/`。A05 随风速、风向和屋顶遮蔽变化，滑翔时减弱并叠入 A06。A09 只在墨潮期间播放；素材未加载或播放失败时继续使用原合成轰鸣。

四段已做首尾交叉淡化、滤波、电平处理和 Ogg 转码，合计约 **2.36 MiB**。A06 采用短阵风循环，没有人为延长成原提示词建议的 30 秒。墨潮配乐 M07 和环境低频 A09 分别受音乐、音效音量控制。

## 来源、许可与验证

AiSHA 的免费授权与 CC0 不同。来源、作者和 [Audio License Agreement](https://aishasound.com/audio-license) 已单独记入 [音频署名](../public/sounds/CREDITS.md)。原始下载留在本地素材目录，并排除 Git 和游戏构建；游戏只包含处理后的四个使用片段。

处理脚本：[prepare-aisha-audio.mjs](../scripts/prepare-aisha-audio.mjs)。参数和哈希：[processed.json](../art/audio/aisha/processed.json)。

已通过完整解码、TypeScript 检查、26 项音频相关测试和生产构建。浏览器静音检查确认四个新文件均为 48 kHz 双声道，能够解码、推进播放并在退出时释放。测试覆盖风声加载失败后的回退、屋顶遮蔽、滑翔结束和墨潮结束。尚未做完整游玩或主观听感验收。
